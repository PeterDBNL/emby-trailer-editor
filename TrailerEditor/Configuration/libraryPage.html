Library scan

Plays each scanned link for a moment, muted, in a hidden YouTube player, the same kind Emby uses. This is the only way to find videos a copyright owner has blocked in other apps. It only runs while this Trailer Library page stays open and visible in a browser window. If you close the page, switch tabs or the computer sleeps, testing pauses and continues where it left off the next time you open this page. Links that already failed the server check, or were tested recently, are skipped.
When Emby reports a YouTube trailer playing, that link is marked as working, so it isn't tested again. Failed trailers never reach the server (they fail in the browser), so this only finds working links. Each reported trailer play is written to the Emby log as "Trailer Editor: trailer playback reported".
Slows the scan down so YouTube doesn't block it. 1000 = about 3,600 links an hour.
Links checked more recently reuse their last result, so weekly scans stay quick. 0 = check every link every time.
